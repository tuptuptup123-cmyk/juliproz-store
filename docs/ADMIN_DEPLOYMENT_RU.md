# Отдельная админка

Один репозиторий, два проекта Vercel. Текущий магазин остаётся без изменений до проверки нового адреса.

Для проекта `juliproz-admin` в команде `juli-e9d0`:

- GitHub: `tuptuptup123-cmyk/juliproz-store`, production branch `main`.
- Root Directory: `admin-deployment`.
- Include source files outside of the Root Directory: включено.
- Framework: Other. Build Command и Output Directory берутся из `admin-deployment/vercel.json`.
- Секреты Telegram и service-role из проекта магазина не копировать. Админка использует текущий публичный конфиг Supabase и права пользователя.

Отдельная сборка содержит редактор, изображения, шрифты и API курса XE. В ней нет каталога, Telegram SDK и webhook. Строгая CSP и запрет встраивания действуют также на главной странице.

Перед переключением проверить на новом адресе вход, перезагрузку, выход, загрузку/обработку фото, сохранение товара и статистику в евро. Вход на новом адресе выполняется заново; токены с адреса магазина не переносить.

После успешной проверки отдельным изменением убрать выдачу админки и её скриптов из сборки магазина, заменить старый адрес переходом на новый и удалить старый `jpAdminSessionV1` до подключения Telegram SDK. До этого изоляция не завершена.

Создание проекта через подключение Vercel сейчас заблокировано ошибкой 403: у подключения нет доступа к команде. Эта ветка только готовит сборку; проект не создан, адрес не опубликован.
