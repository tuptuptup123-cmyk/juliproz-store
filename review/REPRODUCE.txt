Рабочие файлы фото-редактора скачиваются по закреплённым хешам. Браузерные прогоны не должны выполняться одновременно на совпадающих локальных портах.

tests/schema/platform-fixture.sql используется только для SQL-тестов и никогда не применяется к production. Канонический порядок чистой установки — supabase/schema/manifest.json. Для существующей базы применять только новую миграцию; действия после deployment вынесены в supabase/rollout.

Для проверки соответствия живой схемы:
  выполнить supabase/schema/catalog.sql от владельца базы;
  сохранить массив строк {kind,name,definition} в JSON;
  node scripts/check-schema-drift.cjs /path/to/export.json

Архив не содержит .env, паролей, service_role, bot token или выгрузки строк базы. Публичный Supabase anon key в config.js намеренно является публичной частью клиента; безопасность зависит от RLS и прав RPC.
